# 门槛

每条策略过本地回测门之后，固定走三步。一步没走完，不跳到下一步。

## 进聚宽模拟（步骤 1）

- 全样本 + 至少一段样本外（**以本地回测为主**，聚宽分享链接可选）
- 计入手续费和 1 跳滑点后仍有交易，不是偶然几笔
- 1 万资金下回测没有频繁保证金打穿
- 单笔风险写在代码里（新手默认：固定 1 手 + 硬止损）
- 总表挂上聚宽回测分享链接（可暂不公开）

挂上之后：

1. **先自动模拟**（聚宽期货模拟，关机也跑）。
2. **再开聚宽自带通知/邮件**，信号到了在 App 里手动下一手，核对规则能不能执行。仓库不接微信推送。
3. **至少跑 3 个月**，每月把权益、回撤、是否按信号手搓抄回 [paper/leaderboard.md](../paper/leaderboard.md) 和该策略观察页。

FQ-002 挂盘日 2026-09-02，满 3 个月约 **2026-12-02**。

## 进 SimNow 自动（步骤 2）

单条聚宽模拟满 3 个月，且手搓可执行、成本后仍像有交易而不是偶然几笔，才把执行接到 SimNow。由你提供**阿里云**国内机，出站 TCP 到 SimNow 前置；密钥只放服务器本地，禁止进 GitHub。本机 `--send` / 09:05 自动发单在步骤 2 之前不做。

见 [ctp.md](ctp.md)。

## 进实盘自动（步骤 3，现在不做）

SimNow 自动跑稳后再单独评估。不再要求「10 条同时在跑」。1 万变 5 万不是放行条件；放行条件是小资金活得下来、规则可执行。代码拒绝 `environment: live`。
