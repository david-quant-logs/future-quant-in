# 调研协议

每条策略必须按这个顺序走。调研可以很长，未完成不得把状态改成 `backtest`。

## 顺序

1. **先编号**。在 [STRATEGY_INDEX.md](../STRATEGY_INDEX.md) 占一行，状态 `research`。
2. **论文调研**。国内外中低频期货 / CTA 文献，写 `research/FQ-NNN-*.md`。必须单独评估**国内商品期货**适用性，不能把美盘 CTA 结论直接搬过来。
3. **冻结方案**。一页规格：假设、品种、信号、成交时点、仓位、止损、明确砍掉的复杂变体。
4. **实现 + 回测**。聚宽日频 `strategy.py`，迭代写入 `iterations/`。
5. **进模拟或退役**。过门则挂一条模拟；不过门写清原因后 `retired`。
6. **才开下一条**。主题由「上一条学到什么 + 文献还缺哪类证据」决定。

## 频率

只做中低频：日线，或更慢的隔日 / 周频。不做分钟日内。

## 每篇文献笔记要回答

- 可检验命题是什么
- 样本、频率、成本假设
- 能否在 **1 万本金 + 单品种 1 手 + 日频** 下复现核心思想
- 国内市场哪些微观结构会破坏原论文假设（换月、涨跌停、夜盘、平今、投机者占比）
- 新手最小实现：砍掉哪些机构才会用的部分
- 选定方案，以及明确不选的变体

## 检索范围

- 国际：CTA / 时间序列动量 / 趋势跟随；SSRN、期刊、AQR 公开笔记
- 国内：商品期货趋势与动量；Journal of Futures Markets 等英文中国样本、知网、期货公司金研里**有出处**的写法
- 无论文出处的社区策略只当反例，不当选股依据
