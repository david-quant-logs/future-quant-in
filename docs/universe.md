# 1 万本金品种池

模拟和回测初始资金都设 **10000**，避免用 50 万回测、1 万实盘。

只做低保证金、能开 1 手且留安全垫的品种。

| 优先级 | 品种 | 代码 | 说明 |
| --- | --- | --- | --- |
| 优先 | 玉米 | C | 保证金低、波动相对温和，新手容错最好 |
| 优先 | 淀粉 | CS | 与玉米相关，单独做时注意重复暴露 |
| 优先 | 豆粕 | M | 活跃，保证金仍可能 1 手放下 |
| 优先 | 菜粕 | RM | 可与豆粕构成价差，单腿时独立评估 |
| 优先 | 甲醇 | MA | 化工，趋势可能强于农产品，波动更大 |
| 优先 | PTA | TA | 同上 |
| 备选 | PVC | V | 保证金抬升时放弃 |
| 备选 | 玻璃 | FG | 保证金偏高 |
| 备选 | 螺纹 | RB | 文献里趋势常更强，但 1 万容错差 |

排除：股指、原油、黄金、铜、生猪、碳酸锂等（1 手保证金或波动对 1 万不可用）。

选玉米做 FQ-001 **不是**因为文献里它趋势最强。券商研报里黑色系单品种趋势往往更好；选 C 是保证金约束。
